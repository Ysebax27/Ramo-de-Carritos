PROYECTO RAMO HOT WHEELS

ESTRUCTURA:

ramo-hotwheels/
│
├── index.html
├── style.css
├── script.js
│
└── img/
    ├── fondo.jpg
    ├── carro1.png
    ├── carro2.png
    ├── carro3.png
    ├── carro4.png
    └── carro5.png

IMPORTANTE:
Copia tus 6 imágenes dentro de la carpeta "img" con EXACTAMENTE esos nombres.

EJECUTAR DESDE LA TERMINAL DE VS CODE:

1. Abre esta carpeta en Visual Studio Code.
2. Abre Terminal > New Terminal.
3. Ejecuta:

   python -m http.server 8000

En Windows también puedes usar:

   py -m http.server 8000

4. Abre:

   http://localhost:8000

NO NECESITAS LIVE SERVER.

PERSONALIZAR:
- Cambia "fondo.jpg" por tu fondo.
- Cambia carro1.png hasta carro5.png por tus Hot Wheels.
- Los carros están separados de las flores y tienen sus propias animaciones.
- Puedes cambiar los textos directamente en index.html.
